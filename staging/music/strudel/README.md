# Strudel engine (vendored, third-party)

`web-sf-1.3.0.js` is a bundled build of the [Strudel](https://strudel.cc)
live-coding music engine — the "web + soundfonts" combination of
[`@strudel/web`](https://www.npmjs.com/package/@strudel/web) and related
`@strudel/*` packages. It is **third-party software**, vendored into Paramo and
served to every visitor of the web build. It is **not** covered by Paramo's MIT
license.

## How Paramo uses it

`../paramo-music.js` loads this bundle via the web export's `head_include`,
redirects soundfonts to the same-origin `../soundfonts/` directory
(`setSoundfontUrl`), and `repl.evaluate()`s the arrangement
`../ojos_azules.strudel.js`. The Paramo game (Godot → WASM) talks to this engine
only through its public JS API, and the engine is kept as a separate served file
so the two remain separate works (aggregation) — Paramo's own MIT-licensed
source is not combined into the AGPL engine.

> Note: the AGPL banner at the top of `web-sf-1.3.0.js` is added by hand. If the
> engine is ever re-vendored/rebuilt, re-add the banner (it is not regenerated by
> `scripts/tools/sync_music.gd`, which only copies the `.strudel.js` song).
