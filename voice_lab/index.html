Paramo voice lab: mumble speech

One text front end (graphemes → phonemes → syllables, stress, pitch contour) drives every synth, so only the synthesis differs. Type, pick a language, hit play. Ctrl/⌘ + Enter plays the selected engine, Ctrl/⌘ + Shift + Enter plays them all in turn. Each card shows its measured GDScript cost; under ~100 ms per second of speech can run live in the game. Godot bank mode renders each syllable once at a flat pitch and rebuilds the line with pitch_scale: what the web build could actually ship.
